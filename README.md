# MoxChat

[中文文档](./README.zh-CN.md)

This is the MoxChat client distribution repository for Android APKs, Web packages, and PC clients. Client source code and build tools are maintained in the main Mox source repository.

## Downloads

Client packages have not been published here yet. Future downloads will be available through [GitHub Releases](https://github.com/MoxChat/MoxChat/releases), with the supported platform, version, installation instructions, and SHA-256 checksums documented for each release.

| Package | Purpose |
| --- | --- |
| Android APK | Install MoxChat on a compatible Android device. |
| Web package | Deploy the built MoxChat Web client on your own host. |
| PC client | Install or run the desktop client for the platform named in the release. |

Download the package for your platform and verify its checksum before installation or deployment. Keep your existing application data and runtime configuration when updating.

## Repository contents

This repository contains client distribution documentation and published packages only. It does not contain application source code, signing keys, credentials, user data, dependencies, or local build caches. A package being listed above does not mean it is available; consult the published release assets.
